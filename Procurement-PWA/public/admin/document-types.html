Default Approval Chain

Each row is either a fixed role (resolved to whoever holds it at chain-creation time) or a specific person. Tick "parallel with above" to put a row on the same level as the one above it: everyone on a level approves at the same time, in any order, and one rejection sends the document back to the sender. This chain is copied onto new uploads of this type — editing it here does not change chains already in flight.

Document Numbering

Placeholders: {PREFIX} {YYYY} {YY} {MM} {seq} or zero-padded {seq:04d} (the pattern must contain a sequence). A change applies to the next number issued; numbers already issued are not touched.
